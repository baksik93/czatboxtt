# Czatbox TT 0.3.0

## Zmiany

- Naprawiono błąd wersji 0.2.9, który po aktualizacji mógł wyrzucać użytkowników z programu podczas wyboru języka.
- Okno wyboru języka jest teraz uruchamiane tylko raz i dopiero po prawidłowym odczytaniu wersji aplikacji.
- Zabezpieczono zapis języka przed wielokrotnym kliknięciem i równoczesnym przetwarzaniem kilku zmian.
