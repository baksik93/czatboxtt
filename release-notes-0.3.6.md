# Czatbox TT 0.3.6

Wersja testowa przygotowująca wizualne panele aktualizacji i dolny pasek aplikacji.

## Zmiany

- Wewnętrzne, dopasowane do motywu okna aktualizacji zamiast systemowych dialogów Windows.
- Wizualny postęp pobierania aktualizacji.
- Panel informujący o gotowej aktualizacji z przyciskiem ponownego uruchomienia.
- Dolny pasek pod czatem z odnośnikiem do profilu Baksik.
- Poprawione wyśrodkowanie znaku „X” w oknach statystyk.

Wydanie jest publikowane w stabilnym kanale GitHub i obsługuje automatyczną aktualizację wcześniejszych wersji programu.
