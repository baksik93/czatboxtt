# Czatbox TT 0.3.16

- Przeprojektowano przypinane widżety pulpitu: zajmują całą wysokość obszaru roboczego, a notatki korzystają z pozostałej przestrzeni.
- Dodano widżet pięciu ostatnio edytowanych notatek z otwieraniem wpisu w aplikacji.
- Uporządkowano kalendarz: opisane akcje importu i eksportu oraz bezpieczny odstęp przycisków kategorii.
- Ujednolicono centrowanie ikon przycisków i tło głównego obszaru czatu.
